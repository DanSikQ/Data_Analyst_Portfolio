## 📂 Проекты  

### 1. Анализ и прогнозирование сроков доставки вагонов ([папка](/projects/Auto-ML_vs_My_models))

**Задача**: Построить модель прогнозирования сроков доставки и сравнить эффективность ручной настройки моделей с AutoML.

**Методы**:
- EDA (Pandas, NumPy)
- Feature Engineering (создание временных и сезонных признаков)
- Модели градиентного бустинга (XGBoost, CatBoost, LightGBM)
- AutoML (H2O)

**Результат**:
- Лучшая модель: **XGBoost** (MAE 1.65 дня)
- Самый быстрый алгоритм: **LightGBM** (3.32 сек)
- AutoML показал худшие результаты (MAE 1.89 дня)
- Ключевые факторы: нормативные сроки, операции в пути, расстояние

**Вывод**: Ручная настройка моделей превзошла AutoML по точности прогнозирования.
