## 📂 Проекты  
 ### 1. Анализ эффективности пролонгации проектов сотрудниками ([папка](/projects/prolongations))
**Суть:** Расчёт KPI метрик для оценки успешности продления клиентских договоров

**Задача:** Оценить эффективность сотрудников в пролонгации клиентских проектов на основе данных о завершённых проектах и отгрузках.

**Методы:**

- Очистка и агрегация данных (Pandas)

- Расчёт метрик:

    - K1 — доля отгрузок в 1-й месяц после окончания проекта

    - K2 — доля отгрузок во 2-й месяц для "непродлённых" проектов

- Визуализация в Excel

**Результаты:**

- Выявлены топ-сотрудники с высокими K1 и K2.

- Обнаружены сотрудники с низкой пролонгацией (риск потери клиентов).

**Вывод:** Метрики K1 и K2 позволяют объективно оценить вклад сотрудников в сохранение клиентов и выделить зоны для улучшения.

### 2. Анализ и прогнозирование сроков доставки вагонов ([папка](/projects/Auto-ML_vs_My_models))

**Суть:** Сравнение эффективности ручного и автоматического машинного обучения для оптимизации логистики

**Задача**: Построить модель прогнозирования сроков доставки и сравнить эффективность ручной настройки моделей с AutoML.

**Методы**:
- EDA (Pandas, NumPy)
- Feature Engineering (создание временных и сезонных признаков)
- Модели градиентного бустинга (XGBoost, CatBoost, LightGBM)
- AutoML (H2O)

**Результат**:
- Лучшая модель: **XGBoost** (MAE 1.65 дня)
- Самый быстрый алгоритм: **LightGBM** (3.32 сек)
- AutoML показал худшие результаты (MAE 1.89 дня)
- Ключевые факторы: нормативные сроки, операции в пути, расстояние

**Вывод**: Ручная настройка моделей превзошла AutoML по точности прогнозирования.
