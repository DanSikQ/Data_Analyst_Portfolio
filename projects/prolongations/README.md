# 📊 Анализ эффективности пролонгации проектов сотрудниками

**Описание проекта:**

Проект направлен на оценку эффективности сотрудников в продлении (пролонгации) клиентских проектов. 
На основе данных о завершённых проектах и отгрузках были разработаны метрики, позволяющие измерить, 
насколько успешно сотрудники сохраняют клиентов после окончания первоначального срока действия договора.

💡*Отгрузка — это сколько денег клиент заплатил в этом месяце.*

💡*Пролонгация — смогли ли убедить клиента заплатить снова после окончания договора."*

**Цели проекта:**

- Определить ключевые показатели пролонгации проектов.

- Оценить эффективность сотрудников по этим метрикам.

- Сформировать отчёт для регулярного мониторинга.

**📂 Данные содержали:**

1. prolongations.csv:

   - `id` – уникальный идентификатор проекта

   - `month` – последний месяц реализации проекта (формат: YYYY-MM)

   - `AM` – ФИО ответственного аккаунт-менеджера (первичный ключ)

2. financial_data.csv:

   - `id` – идентификатор проекта (возможны дубли)

   - `Причина дубля` – объяснение повторяющихся ID

   - Колонки с месяцами (например, `2023-01`, `2023-02`) – суммы отгрузок

   -   `Account` – ФИО менеджера (могут отличаться от prolongations.csv)

## 🔧 Методология анализа
### 1. Обработка данных
Привёл сырые данные к аналитическому формату:

- Стандартизировал названия колонок и формат значений

- Очистил от некорректных записей ("стоп", "в ноль") и артефактов форматирования

- Агрегировал дублирующиеся записи проектов, суммируя финансовые показатели

- Для каждого проекта оставил единую запись с актуальным ответственным менеджером

Данные готовы для расчёта метрик пролонгации и дальнейшего анализа
### 2. Расчёт коэффициентов пролонгации
Были введены две метрики:

**Коэффициент пролонгации в первый месяц (К1)**

$K_1 = \frac{\text{Сумма отгрузок в 1-й месяц после окончания}}{\text{Сумма отгрузок в последний месяц реализации}}$

*Интерпретация*: Показывает, какая доля проектов была успешно продлена сразу после завершения.

**Коэффициент пролонгации во второй месяц (К2)**

 $K_2 = \frac{\text{Сумма отгрузок во 2-й месяц после окончания}}{\text{Сумма отгрузок проектов, не продлённых в 1-й месяц}}$

Интерпретация: Отражает способность сотрудников "возвращать" клиентов, которые изначально не продлили проект.

### 3. Визуализация и отчётность
**Создан Excel-отчёт с таблицами и графиками:**

- Рейтинг сотрудников по коэффициентам пролонгации.

- Сравнение K1 и K2 в разрезе месяцев.

- Выводы по эффективности работы команд.

*Excel файл с отчётом закреплён под названием "Отчёт.xlsx"*

## 🎯 Результаты
- Выявлены топ-сотрудники с высокими K1 и K2.

- Обнаружены проблемные зоны — 30% сотрудников имеют низкий коэффициент пролонгаций.

- Excel — для визуализации и отчёта.
