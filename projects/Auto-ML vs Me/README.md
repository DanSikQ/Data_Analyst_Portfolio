# 🚂 Анализ и прогнозирование сроков доставки вагонов

**Цель проекта**: Построение модели машинного обучения для предсказания времени доставки вагонов на основе исторических данных.
И сравнение результатов с AutoML

**Целевая переменная**:  
`Срок доставки фактический` (в днях)  
- **Среднее значение**: 8.85 дней  
- **Стандартное отклонение**: 7.75 дней  

---

## 📂 Описание данных  
Данные содержат информацию о перемещении вагонов, включая:  
- **Характеристики вагонов**: тип, грузоподъемность, вес груза.  
- **Маршрут**: расстояние, станции отправления и назначения.  
- **Операционные данные**: дата отправления, тип операции (погрузка/разгрузка).  
- **История поломок**: наличие задержек из-за технических неисправностей.  
- **Внешние факторы**: сезонность, логистические условия.  

---

## Этапы работы  

##  1. 🔍 Exploratory Data Analysis (EDA)  
- **Анализ распределений**: Изучены распределения числовых, категориальных и временных признаков.  
- **Обработка пропусков**:  
  - Заполнение медианой/модой для числовых и категориальных данных.  
  - Удаление некритичных столбцов с высоким % пропусков.  
- **Работа с аномалиями**:  
  - Удалены выбросы.  
  - Скорректированы нереальные значения веса/расстояния.  

## 2. ⚙️ Feature Engineering  
- **Удалены неинформативные признаки**:  
  - Столбцы с уникальными значениями (ID, названия без смысловой нагрузки).   
- **Созданы новые признаки**:   
  - Временные характеристики (количество дней до планового ремонта вагона)  
  - Признаки сезонности.  
  - Бинарные флаги событий (наличие операции).  

  
## 3. 🤖 Выбранные алгоритмы
| Алгоритм     | Тип                | Преимущества                          | Недостатки                     |
|--------------|--------------------|---------------------------------------|--------------------------------|
| **CatBoost** | Градиентный бустинг | Лучшая работа с категориальными данными | Высокие требования к памяти    |
| **XGBoost**  | Градиентный бустинг | Максимальная точность                 | Долгое время обучения          |
| **LightGBM** | Градиентный бустинг | Самая высокая скорость                | Склонность к переобучению      |

Противостоять этим алгоритмам будет AutoML - библиотека `h20`

_Для каждого алгоритма был проведён подбор параметров для более честных сравнений_

## 4. 🏆 Сравнение моделей
Результаты оценки их эффективности представлены в таблице:

*Лучшим алгоритмом в AutoML оказался StackedEnsemble - его результаты продемонстрированы в таблице*

| Модель       | MSE       | MAE       | RMSE      | Время обучения (сек) |
|--------------|-----------|-----------|-----------|----------------------|
| **XGBoost**  | 5.826215  | 1.652811  | 2.413755  | 58.78                |
| **CatBoost** | 5.929149  | 1.688633  | 2.434984  | 628.99               |
| **LightGBM** | 6.222201  | 1.711983  | 2.494434  | 3.32                 |
| **H2O AutoML**| 7.996800 | 1.892731 | 2.827861  | 147.45               |


### Ключевые выводы:
1. **XGBoost показал наилучшую точность**:
   - Минимальные ошибки по всем метрикам (MSE, MAE, RMSE)
   - MAE = 1.65 дня (лучший результат среди всех моделей)

2. **LightGBM - оптимальный выбор для быстрого развертывания**:
   - Время обучения всего 3.32 секунды (в 18 раз быстрее XGBoost)
   - Точность близка к XGBoost (разница в MAE всего 0.06 дня)

3. **My model vs AutoML**:
   - Мои модели, за счёт тщательного подбора параметров, значительно превосходит AutoML по точности
   - AutoML не оправдал ожиданий, показав худшие результаты при среднем времени обучения

### Ключевые переменные

Ключевыми переменными в обучении стали

1. `Отведённое количество суток на доставку по нормативам`
2. `Планируется ли операция во время рейса`
3. `Расстояние общее`

---

## 🎯 Итоги
Лучший результат показал **XGBoost** 🏆, но для быстрых экспериментов идеален **LightGBM** ⚡. AutoML в данном случае не смог превзойти ручную настройку моделей.
